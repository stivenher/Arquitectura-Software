# Sistema Inteligente de Movilidad Urbana (Smart Mobility System)

## Taller 1 – Arquitectura de Software

**Estudiante:** Stiven Hernández

**Asignatura:** Arquitectura del Software


# Introducción

El presente documento desarrolla la propuesta arquitectónica de un Sistema Inteligente de Movilidad Urbana, elaborada como parte del Taller 1 de la asignatura Arquitectura del Software. Este trabajo tiene como finalidad poner en práctica los conceptos estudiados durante el curso mediante el diseño de una solución tecnológica que contribuya a optimizar la movilidad dentro de las ciudades.

La propuesta busca facilitar la gestión del tráfico mediante el monitoreo continuo de las vías, el control inteligente de los semáforos y la recomendación de rutas más eficientes para los usuarios. Además, el sistema permite recopilar y procesar la información proveniente de sensores distribuidos en diferentes sectores urbanos, con el fin de detectar situaciones como congestiones vehiculares, accidentes o cualquier otro evento que pueda afectar la circulación y generar las respectivas alertas.

----------

# Objetivos

-   Monitorear de manera permanente el comportamiento del tráfico en la ciudad.
-   Administrar el funcionamiento de los semáforos inteligentes de acuerdo con las condiciones del flujo vehicular.
-   Brindar a los usuarios alternativas de rutas que permitan reducir tiempos de desplazamiento.
-   Integrar el sistema con aplicaciones móviles para ofrecer información actualizada y de fácil acceso.
-   Procesar los datos capturados por los sensores urbanos para apoyar la toma de decisiones.
-   Emitir notificaciones cuando se presenten incidentes, accidentes o niveles elevados de congestión.
